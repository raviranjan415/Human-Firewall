How to get started

  1. Create a free account — you only need a username and e-mail.
  2. Open your dashboard to see your level, XP and recommended next step.
  3. Work through the practical labs in order; each one builds on the last.
  4. Add video lessons, comics and games alongside the labs whenever you like.

Why is a lab locked?

Labs have prerequisites so the difficulty climbs gradually. A lab only unlocks once the previous lab has been passed. If you see a lock, open the earlier lab and complete it first — the lock will clear automatically. Completion is checked on the server before XP is awarded, so passing is what counts, not simply opening the page.

How certificates work

Certificates are tied to how many labs you have completed, and each has a default passing score of 80%:

  • 30 labs — first tier
  • 60 labs — second tier
  • 90 labs — third tier
  • 100 labs — full pathway

Once you are eligible, you can generate the certificate, download it as a PDF, and share it. Anyone can confirm a certificate is genuine using its verification code on the {{ t('cert.verify') }} page.

How to change the language

Use the language menu in the top navigation bar, or the language links on the home page. You can also set a default language in your Settings. Switching language never affects your progress.

I forgot my password

On the sign-in page, choose “{{ t('auth.forgot') }}” and enter your e-mail. Follow the reset link to choose a new password. The link is time-limited, so if it has expired simply request a new one.

Troubleshooting

A page will not load or looks broken

Refresh the page. If it persists, try clearing your browser cache or opening the site in a different browser. Some pages need JavaScript enabled.

My XP or progress did not update

Progress is saved when an activity is properly completed, not when it is opened. Retry the activity and check that it shows as completed before refreshing.

I got a “Too many requests” message

Rate limiting protects your account and the service from abuse. Wait a short while, then try again — see the home page if you need to start over.

I cannot generate my certificate

Check that you have completed enough labs for the tier and met the pass score. The certificates page shows how many more you need.

Password reset e-mail never arrived

In local development no e-mail service is configured, so no reset e-mail is sent. Instead, the reset link is shown directly on screen only when the app is running in debug mode. For real deployments an administrator must configure mail.
